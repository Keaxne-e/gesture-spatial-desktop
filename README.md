# Real-Time Gesture-Controlled Spatial Desktop

A real-time computer vision project for controlling virtual objects using hand gestures.

## Planned Features

- Real-time hand tracking
- 21 hand-landmark detection
- Pinch-to-grab interaction
- Object translation and rotation
- Two-hand scaling
- Temporal gesture recognition
- FPS and latency benchmarking

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- PyTorch
